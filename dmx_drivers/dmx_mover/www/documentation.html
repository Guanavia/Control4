DMX Moving Head (LensShift)

A moving head as one Control4 light: one driver, one load. Intensity and color are the native light (slider, color picker, scenes, keypads, voice, Room Off). Position, beam, effects and presets are set up in Composer (the Aim properties and the preset Actions) and driven by programming (Recall Preset, Set Position, Set Control), so clients use them through scenes, keypads and Custom/Experience buttons. There is no separate "position" load.

It outputs through an Art-Net Node driver (same driver set).

Quick start

  1. Add an Art-Net Node driver for the universe first.
  2. Add this driver, choose the Fixture Type and Layout, and set the Start Address set on the fixture.
  3. In Connections, bind this driver's Art-Net Node input to the node driver's Fixtures output.
  4. Set the Pan/Tilt Min/Max soft limits so the head cannot point anywhere it should not (into eyes, at a wall).
  5. Aim the head with Aim Pan / Aim Tilt (or the Nudge Actions), then save presets with the preset Actions.

A moving head needs its channels to itself. If any other fixture overlaps it, the later one is refused and outputs nothing; Status says what it collides with.

Custom layouts

As for the DMX Light: set Layout to Custom (it starts from the running layout) and edit Channel Count / Channel N Function / Channel N Default, or the Channel Map, e.g. pan,pan_fine,tilt,tilt_fine,pt_speed,dimmer,strobe,red,green,blue,white,reset. With a Reset/Control channel, set Reset Value and Reset Hold (ms) from the fixture manual. A layout needs at least a Pan or a Tilt channel.

Aiming and presets in Composer

Navigator does not show an Extras tab for lights on current Control4 systems (tested on the app and a T4, OS 4.1, with a minimal test driver). The driver still offers Extras in case a later OS shows them, but nothing depends on them: everything is done from Composer and programming.

  1. Aim: set Aim Pan (%) and Aim Tilt (%) (percent of full travel; each Set moves the head). For fine work, choose a Nudge Size and use the Nudge Left / Nudge Right / Nudge Up / Nudge Down Actions; Home Position centres it in the soft limits. The Aim properties always show where the head actually is, after limits, nudges, presets and programming.
  2. Save: pick the Selected Preset slot, type a Preset Name, choose Save Mode, and run Save Current Look to Selected Preset.
  3. Use: recall presets from programming (Recall Preset) on keypads, scenes and Custom/Experience buttons, or link them to lighting scenes (below).

Beam and effect channels (strobe, zoom, gobo, macros, programs, Amber/UV) are driven with the Set Control programming command.

Presets

Up to 32 presets, saved on the controller and kept across reboots. A preset stores, depending on what was chosen at Save:

  • Position: pan, tilt and pan/tilt speed.
  • Color: brightness and color. Recall goes through the normal light path, so Navigator shows the right level and color.
  • Everything: also beam and effect channels.

Reset is never stored. A preset saved with a different layout still recalls: channels the current layout lacks are skipped.

Positions in lighting scenes

Advanced Lighting scenes carry brightness and color only. To make a scene also move the head, link a preset to the scene:

  1. Put this light in the scene as normal (its brightness and color come from the scene).
  2. Activate the scene once (from Navigator, a keypad, anywhere).
  3. Aim the head, select a Preset slot and Save (Save Mode "Position only" is usual).
  4. Run the Action Link Selected Preset to Last Scene.

From then on, every time that scene activates, the head also moves to the preset. The scene still owns intensity and color, and keypad LED tracking for the scene works as normal. Linked scenes are listed in Scene Links. Unlink by activating the scene and running the Action Unlink Last Scene.

For a keypad button without a scene, use the Recall Preset programming command.

Troubleshooting

SymptomCheck
Status: REFUSED: overlaps ...Another fixture uses some of this head's channels. Move one of them.
Head moves the wrong wayInvert Pan / Invert Tilt.
Head will not reach a positionThe soft limits clamp it; check Pan/Tilt Min/Max.
Moves are steppyUse a layout with Pan Fine and Tilt Fine (the 16ch ColorKey layout).
Speed runs backwardsSome fixtures run speed fast-to-slow. Use Custom and adjust, or set the speed slider to the other end.
A linked scene does not move the headCheck Scene Links. The link is to the scene that was activated last before pressing Link.
