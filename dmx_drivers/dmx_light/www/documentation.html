DMX Light (Art-Net)

Any DMX fixture that does not move (a single-color dimmer, tunable white, RGB, RGBW or RGB + tunable white fixture, or a high-end multi-emitter fixture) as one native Control4 light. It has the normal brightness slider and color picker, works in Advanced Lighting scenes, keypads, voice and Room Off, and drives the fixture's other channels (strobe, programs, macros, UV...) with the Set Control programming command, so clients reach them through scenes, keypads and Custom/Experience buttons.

It outputs through an Art-Net Node driver (same driver set). One DMX Light controls one circuit: several physical fixtures set to the same DMX address are one circuit.

Quick start

  1. Add an Art-Net Node driver for the universe first.
  2. Add this driver, choose the Fixture Type, set the Start Address set on the fixture, then Channel Count and each channel's function (or paste the Channel Map). Choosing a type fills in its usual channels as a starting point.
  3. In Connections, bind this driver's Art-Net Node input to the node driver's Fixtures output.
  4. Status should read OK: DMX 1-4 on 'Node name'. Use Identify to flash the fixture.

Every type can also use the extended functions, driven by Set Control: Strobe/Shutter, Strobe Duration, Zoom, Focus, Iris, Frost, Color Macro, Macro Speed, Program/Auto, Sound Sensitivity. Amber, UV, Lime and Cyan are Set Control channels on the RGB types too. Every type can use Fixed Value (always outputs its Default) and Unused.

Changing Fixture Type keeps the channels if they still suit the new type, otherwise it starts from the new type's usual channels.

Channels

Set Channel Count to the number of channels the fixture uses in its current DMX mode, then each Channel N Function (and Channel N Default where needed). Or type or paste the Channel Map, e.g. dimmer,red,green,blue,white,strobe:8,fixed:255: each entry is a function, optionally :default; function names or their labels both work. The two forms mirror each other. Paste the Channel Map into another fixture to copy it.

Channel N Default is the value a channel rests at. Set Strobe/Shutter's Default to the fixture's "open / no strobe" value. Fixed Value channels always output their Default. Set Control values are raw 0-255.

Brightness and color

  • With a Dimmer channel, brightness drives the dimmer and the color channels stay at full color.
  • With no Dimmer channel (e.g. a 4-channel RGBW par), brightness scales the color channels (a virtual dimmer), with a 2.2 curve so low levels are usable.
  • Colors from the picker are mixed into Red/Green/Blue. The part common to all three moves to White when the fixture has one (see White Mix).
  • Color temperature uses a CCT channel, or mixes Warm/Cool White, or makes the white from the color channels.
  • Amber, UV, Lime and Cyan have no place in the color picker. Drive them with Set Control.
  • All fades run on the Art-Net Node, so scenes across many fixtures stay in step.

Extended channels

Navigator does not show an Extras tab for lights on current Control4 systems (tested on the app and a T4, OS 4.1, with a minimal test driver). The driver still offers Extras in case a later OS shows them, but nothing depends on them: every channel that is not brightness or picker color (and, for Manual Color, every color channel) is driven with the Set Control programming command, value 0-255. Build client controls as Custom or Experience buttons, keypad buttons or scenes that run Set Control (e.g. "Strobe Fast", "Strobe Off"). Channel N Default sets each channel's resting value; Restore Control Defaults returns them all to it. To try values by hand, use the Art-Net Node's Channel Test.

Sharing channels

Two DMX Lights may use the same channels (for example the same address on purpose). Shared channels merge highest-takes-precedence and both Status fields say so. Program and strobe channels merge the same way, so one light in a program mode pulls the other into it. A DMX Light that overlaps a moving head is refused.
