DMX Light (Art-Net)

Any DMX fixture that does not move (a dimmer, tunable-white fixture, color par or wash, strobe or effect) as one native Control4 light. It has the normal brightness slider and color picker, works in Advanced Lighting scenes, keypads, voice and Room Off, and puts the fixture's other channels (strobe, programs, macros, UV...) on the light's Extras tab.

It outputs through an Art-Net Node driver (same driver set). One DMX Light controls one circuit: several physical fixtures set to the same DMX address are one circuit.

Quick start

  1. Add an Art-Net Node driver for the universe first.
  2. Add this driver, choose the Fixture Type, then a Layout (a built-in channel stack or Custom), then the Start Address set on the fixture.
  3. In Connections, bind this driver's Art-Net Node input to the node driver's Fixtures output.
  4. Status should read OK: DMX 1-4 on 'Node name'. Use Identify to flash the fixture.

Custom layouts

Set Layout to Custom. Selecting Custom starts from the layout that was running, so a built-in can be tweaked. Then either:

  • set Channel Count and each Channel N Function / Channel N Default, or
  • type or paste the Channel Map, e.g. dimmer,red,green,blue,white,strobe:8,fixed:255. Each entry is a function, optionally :default. Function names or their labels both work. Editing the Channel Map switches the layout to Custom.

The two forms mirror each other. Paste the Channel Map into another fixture to copy a layout.

Channel N Default is the value a channel rests at. Set Strobe/Shutter's Default to the fixture's "open / no strobe" value. Fixed Value channels always output their Default. Custom Extras controls are raw 0-255 sliders, because the driver cannot know a custom fixture's program ranges.

An invalid change is refused and explained in Status, and the fixture keeps running its previous layout. A Start Address that would run past channel 512 is reverted to the last good address.

Brightness and color

  • With a Dimmer channel, brightness drives the dimmer and the color channels stay at full color.
  • With no Dimmer channel (e.g. a 4-channel RGBW par), brightness scales the color channels (a virtual dimmer), with a 2.2 curve so low levels are usable.
  • Colors from the picker are mixed into Red/Green/Blue. The part common to all three moves to White when the fixture has one (see White Mix).
  • Color temperature uses a CCT channel, or mixes Warm/Cool White, or makes the white from the color channels.
  • Amber, UV, Lime and Cyan have no place in the color picker. They are sliders on the Extras tab.
  • All fades run on the Art-Net Node, so scenes across many fixtures stay in step.

Extras tab

Every non-light channel in the layout appears on the light's Extras tab in Navigator. Built-in layouts show program and macro channels as named steps. Custom layouts show raw 0-255 sliders. Restore Defaults returns every Extras control to its channel default.

Sharing channels

Two DMX Lights may use the same channels (for example the same address on purpose). Shared channels merge highest-takes-precedence and both Status fields say so. Program and strobe channels merge the same way, so one light in a program mode pulls the other into it. A DMX Light that overlaps a moving head is refused.
