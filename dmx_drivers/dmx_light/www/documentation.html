Adv DMX Light (LensShift)

Any DMX fixture that does not move (a single-color dimmer, tunable white, RGB, RGBW or RGB + tunable white fixture, a high-end multi-emitter fixture, or a pixel fixture such as a pixel bar, a segmented wash or pixel tape) as one native Control4 light. It has the normal brightness slider and color picker, works in Advanced Lighting scenes, keypads, voice and Room Off, and drives the fixture's other channels (strobe, programs, macros, UV...) with the Set Control programming command, so clients reach them through scenes, keypads and Custom/Experience buttons.

It outputs through either an Art-Net Node driver (same driver set) or a Control4 DMX gateway such as the Creative Lighting eDIDIO, through that gateway's own Control4 driver. Bind one or the other. One DMX Light controls one circuit: several physical fixtures set to the same DMX address are one circuit.

Quick start

  1. Have an output in the project: an Art-Net Node driver, or the gateway's driver (e.g. Creative Lighting eDIDIO DMX/DALI).
  2. Add this driver, choose the Fixture Type and set the Start Address set on the fixture. Then describe its channels (see Describing a fixture): for most fixtures that means Channel Count and each channel's function; for a pixel fixture it also means Pixel Count. Choosing a type fills in its usual channels as a starting point.
  3. Read Layout Summary against the channel table in the fixture's manual.
  4. In Connections, bind one input: Art-Net Node to the node driver's Fixtures output, or DMX Gateway to the gateway driver's DMX connection. If the gateway has two DMX lines, set Gateway Line.
  5. Status should read OK: DMX 1-4 (4 ch) on 'Node name' or ... on DMX gateway line 1. Use Identify to flash the fixture.

Describing a fixture

Work from the DMX channel table in the fixture's manual, for the DMX mode the fixture is set to. Fixtures come in two shapes.

1. One color for the whole fixture (most fixtures)

Pars, washes, single-color tape and most bars: the manual lists each channel once, e.g. 1 Dimmer, 2 Red, 3 Green, 4 Blue, 5 White, 6 Strobe. Leave Pixel Count at 1, set Channel Count to the number of channels, and set each Channel N Function in order. Channel N is the manual's channel N.

2. Pixel fixtures: the same group of channels, repeated

Pixel bars, segmented fixtures and pixel tape give every pixel (or segment) its own channels, and the manual lists one group and repeats it: 1 Red 1, 2 Green 1, 3 Blue 1, 4 White 1, 5 Red 2, 6 Green 2 .... Some also have a few master channels that act on the whole fixture (a master dimmer, a strobe, a program channel), usually before the first pixel.

  1. Choose the Fixture Type by what ONE pixel has (RGB, RGBW, RGB + Tunable White, Single Color...).
  2. Set Pixel Count to the number of pixels or segments. The driver splits the current channels for you: the color channels become one pixel's group, anything else (master dimmer, strobe...) stays a fixture channel.
  3. Check Channels Per Pixel and each Pixel Channel N Function, in the manual's order for one pixel.
  4. Under Fixture Channels, list the master channels (Channel Count is 0 if there are none), and set Fixture Channels Before Pixels to how many of them come before the first pixel. The rest come after the last pixel.
  5. Read Layout Summary: it numbers every channel the way the manual does.

Every pixel shows the same color and brightness. The fixture is one Control4 light: one brightness slider, one color, one scene member. Chases, gradients and other per-pixel effects are outside what this driver does.

Zones: to control parts of one pixel fixture separately, add one DMX Light per part. Give each its own Start Address (where that part's first pixel starts) and Pixel Count. Example: an 18-pixel RGBW bar at address 1 as two halves, one driver at address 1 with 9 pixels and one at address 37 with 9 pixels. If the fixture has master channels, give them to one of the zones only.

Checking a fixture against the manual

Manufacturer documentation for pixel fixtures is often wrong about how many pixels there are and in which order their channels run. Confirm it with the Art-Net Node's Channel Test before trusting a setup:

  1. Set the node's Test Start Channel to this fixture's Start Address and Test Channels to two pixels' worth (8 for RGBW).
  2. Raise each Test Ch slider in turn. The first group should light only the first pixel, in the manual's color order; the second group only the next pixel.
  3. Move Test Start Channel to the last pixel (Start Address + Footprint - Channels Per Pixel) and confirm it is the last pixel, and that nothing past it lights.
  4. Turn Channel Test Off.

If the colors shift along the fixture (pixel 2 lights green when red is raised), Channels Per Pixel is wrong. If only part of the fixture lights, Pixel Count is too low, or the fixture is in a different DMX mode from the one in its manual.

Output through a DMX gateway (eDIDIO)

Bind the DMX Gateway input to the gateway's Control4 driver. The gateway driver owns the network link; this driver sends channel values to it, and the gateway runs the fades. It sits on the gateway beside Control4's own DMX Light drivers.

  • Which gateway is chosen by the binding in Connections. With several gateways in the project, check the binding.
  • Gateway Line picks the gateway's DMX output the fixture is wired to. It is always shown and lists only the lines the gateway reports as DMX, so it always says which line the fixture is on; with one DMX line it is selected automatically. The gateway's driver reports its lines when it connects to the gateway: if only the current line is listed and Status says the lines are not reported yet, run the gateway driver's Connect to Edidio action.
  • Start Address is the address on that line. Changing the address or the line returns the channels no longer used to 0.
  • If the gateway goes offline the light shows offline; when it returns, the whole look is sent again.
  • Not checked on a gateway: overlap with other fixtures. The Art-Net Node refuses a light on a moving head's channels and reports shared channels; a gateway does not. Keep addresses apart from Control4's own DMX lights on the same line.

The type says how the fixture maps onto Control4's lighting controls, not which product it is. Choose it by the fixture's emitters, then describe its channels.

On a pixel fixture the type describes one pixel, and the channels it needs (for RGBW: red, green, blue and white) may be pixel channels, fixture channels, or both.

Every type can also use the extended functions, driven by Set Control: Strobe/Shutter, Strobe Duration, Zoom, Focus, Iris, Frost, Color Macro, Macro Speed, Program/Auto, Sound Sensitivity. Amber, UV, Lime and Cyan are Set Control channels on the RGB types too. Every type can use Fixed Value (always outputs its Default) and Unused.

Changing Fixture Type keeps the channels if they still suit the new type, otherwise it starts from the new type's usual channels. On a pixel fixture the pixel count is kept, the pixel group becomes the new type's usual channels, and the master channels the new type still allows are kept.

Channel Map text

The Channel Map is the whole layout as one line, kept in step with the Channel and Pixel properties in both directions. Each entry is a function, optionally :default, e.g. dimmer,red,green,blue,white,strobe:8,fixed:255; function names or their Composer labels both work. A pixel group is written count x (channels), e.g. 18x(red,green,blue,white), and sits where its channels sit on the wire: dimmer,strobe,4x(red,green,blue),program is Dimmer, Strobe, four RGB pixels, then Program. Only one pixel group is allowed. Paste the Channel Map into another fixture to copy it.

Channel N Default / Pixel Channel N Default is the value a channel rests at. Set Strobe/Shutter's Default to the fixture's "open / no strobe" value. Fixed Value channels always output their Default. Set Control values are raw 0-255.

An invalid change is refused and explained in Status, and the fixture keeps running its previous channels. A Start Address that would run past channel 512 is reverted to the last good address. A layout of more than 512 channels (for example 130 RGBW pixels) is refused with the arithmetic.

Brightness and color

  • With a Dimmer channel, brightness drives the dimmer and the color channels stay at full color.
  • With no Dimmer channel (e.g. a 4-channel RGBW par), brightness scales the color channels (a virtual dimmer), with a 2.2 curve so low levels are usable.
  • Colors from the picker are mixed into Red/Green/Blue. The part common to all three moves to White when the fixture has one (see White Mix).
  • Color temperature uses a CCT channel, or mixes Warm/Cool White, or makes the white from the color channels.
  • Amber, UV, Lime and Cyan have no place in the color picker. Drive them with Set Control.
  • On a pixel fixture every pixel gets exactly the color and level a single fixture would; a master dimmer, when there is one, carries the brightness.
  • All fades run on the Art-Net Node, so scenes across many fixtures, and every pixel of one fixture, stay in step.

Extended channels

Navigator does not show an Extras tab for lights on current Control4 systems (tested on the app and a T4, OS 4.1, with a minimal test driver). The driver still offers Extras in case a later OS shows them, but nothing depends on them: every channel that is not brightness or picker color (and, for Manual Color, every color channel) is driven with the Set Control programming command, value 0-255. Build client controls as Custom or Experience buttons, keypad buttons or scenes that run Set Control (e.g. "Strobe Fast", "Strobe Off"). Channel N Default sets each channel's resting value; Restore Control Defaults returns them all to it. A control that is a pixel channel (a per-pixel strobe, say) appears once in Set Control and is applied to every pixel. To try values by hand, use the Art-Net Node's Channel Test.

Sharing channels

Two DMX Lights may use the same channels (for example the same address on purpose). Shared channels merge highest-takes-precedence and both Status fields say so. Program and strobe channels merge the same way, so one light in a program mode pulls the other into it. A DMX Light that overlaps a moving head is refused.
