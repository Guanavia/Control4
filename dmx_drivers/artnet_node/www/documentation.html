Art-Net Node

Part of the DMX over Art-Net driver set: Art-Net Node (this driver), Adv DMX Light (LensShift) and DMX Moving Head (Art-Net).

One Art-Net Node driver owns one DMX universe on one Art-Net node (for example a Pknight CR011R). Fixture drivers bind to it in Connections. The node driver merges every fixture's channels into a single 512-channel frame, runs all fades, and sends it to the node as Art-Net (ArtDmx, unicast, UDP 6454).

This set is independent of Control4's own DMX system (Vibrant DALI/DMX gateway + DMX Light Driver). Use a separate universe.

Quick start

  1. On the node, set Art-Net → DMX output mode, a static IP on the Control4 LAN, and its Net / Sub-Net / Universe.
  2. Add this driver and set Node IP Address, Art-Net Net, Art-Net Sub-Net and Art-Net Universe to match the node exactly.
  3. Add an Adv DMX Light (LensShift) or DMX Moving Head (Art-Net) per fixture circuit and, in Connections, bind each fixture's Art-Net Node input to this driver's Fixtures output.
  4. Check Status and Patch.

Use a static IP (or a DHCP reservation) for the node. Art-Net is sent unicast to the address in Node IP Address. If the node's address changes, the lights stop responding and nothing else will tell you why.

Actions

ActionWhat it does
Resend FrameSends the current frame immediately.
Blackout UniverseOutputs zero on every channel until any fixture changes. Temporary: nothing is lost.
Re-sync FixturesAsks every bound fixture to register again and resend all of its channels.

How fixtures share the universe

  • Lights may share channels. Two DMX Lights on the same addresses are a legitimate choice. Shared channels merge highest-takes-precedence, and both fixtures show that they share. If the two have different start addresses or layouts, a warning says it is almost certainly a patching mistake.
  • Moving heads may not. A moving head that overlaps any other fixture, or any fixture that overlaps a moving head, is refused: it outputs nothing and its Status says what it collides with. The fixture that registered first keeps running. Fix the address and the refused fixture is accepted automatically.
  • Only one Art-Net Node driver may send to a given node IP and Net / Sub-Net / Universe. A node merges at most two sources, and two drivers would fight. Both drivers warn if they find each other.

Troubleshooting

SymptomCheck
Status: NOT SENDINGNode IP Address is empty or not a valid unicast address.
Status: NODE NOT REACHABLEThe node did not answer ping. Check its IP, power and network. Art-Net is UDP, so without ping the driver could not tell whether anything is listening.
Sending, reachable, but lights darkNet / Sub-Net / Universe differ from the node; the node is not in Art-Net-to-DMX output mode; DMX cable or fixture address. Use the Channel Test properties on the fixture's channels.
A fixture is missing from PatchIts Art-Net Node input is not bound to Fixtures, or it has a layout error. Check that fixture's Status. Re-sync Fixtures asks every bound fixture to register.
Lights flicker between two looksAnother Art-Net source (another driver, QLC+, a console) is sending to the same universe.
