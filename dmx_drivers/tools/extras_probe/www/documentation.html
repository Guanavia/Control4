Extras Probe (test only)

A diagnostic light with no output. It exists to answer one question: can a light driver show an Extras tab on this system's Navigators at all?

  1. Add it to any room. It loads as a dimmer and immediately offers one Extras checkbox.
  2. Open the light on a Navigator (app or touch screen) and look for an Extras tab.
  3. If nothing appears, try the Actions Send: Switch (Hue shape) and Send: List, checking after each.
  4. The Lua output logs every message the proxy or a UI sends, including whether a UI ever asks for Extras, and any Extras value Navigator sends back.
  5. Delete the device afterwards.
